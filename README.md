# copathy

Windows のエクスプローラーで選んだファイル・フォルダのパスを、**Ctrl+Alt+C** でまとめてコピーするツールです。

- Ctrl+Alt+C が効くのはエクスプローラーが前面にあるときだけです。ほかのアプリには影響しません
- タスクトレイに常駐し、サインイン時に自動で起動します

## インストール

1. 緑の **Code** ボタン → **Download ZIP** でダウンロードして展開します
2. 展開したフォルダの **「copathy をインストール」** をダブルクリックします

「copathy をインストールしました」と通知が出れば完了です。セキュリティの警告が出たら **実行** を押してください（**詳細情報** と出たら、それを押してから **実行**）。1 分たっても何も出ないときは、ウイルス対策ソフトに止められている可能性があります。

## 使い方

エクスプローラーでファイルやフォルダを選んで **Ctrl+Alt+C** を押すと、パスがコピーされます。

ファイル 1 つ

```
C:\Work\file1.txt
```

フォルダ 1 つ

```
C:\Work\Docs\
```

同じフォルダ内で複数選択

```
C:\Work\
Docs\
Images\
archive.zip
file2.txt
file10.txt
```

親フォルダがばらばら（検索結果など）

```
C:\Work\Docs\
Sub\
a.txt
b.txt

C:\Work\Images\logo.png
D:\Backup\old.txt
```

- フォルダが先、ファイルが後です。名前は数字を数として並べます（file2 → file10）
- 同じフォルダから 2 つ以上選んだものは、フォルダのパスの下に名前を並べます。1 つだけのものは、最後にフルパスでまとめます

トレイのアイコンを右クリックすると、バージョンの確認、GitHub を開く、更新の確認、終了ができます。

## 更新

起動時に新しい版を確認し、あれば自動で更新します。更新の内容は [Releases](https://github.com/ogura-ryoya/copathy/releases) で確認できます。

## アンインストール

トレイのアイコンを右クリックして **終了** を押し、`%LOCALAPPDATA%\copathy` フォルダを削除してください。

## 動作環境

Windows 10 / 11（追加のインストールは不要です）。会社の PC などで PowerShell スクリプトの実行が禁止されている場合は動きません。

## 開発者向け

`copathy.ps1` の `$Version` を上げて main に push すると、GitHub Actions が検証してリリースを作ります。リリースノートは前回のリリース以降のコミットメッセージから作られます。
